# Photo Pick · PP-1

[모바일 웹앱](https://racheu107.github.io/photo-pick-pp1/) · [Android 릴리스](https://github.com/racheu107/photo-pick-pp1/releases/latest)

SD카드 사진을 찍은 날짜별로 꺼내 보고, 키 세 개(별로·좋음·매우 좋음)로 평가해 고른 원본만 휴대폰에 옮기는 앱. 현재 버전 **0.5.1** (web-pp1-auto 화면).

## 0.5.1 — 2026-10-15
- 사용자 제보 4건 + 독립 사용성 평가(실제 터치 입력) 반영
- 핀치 확대: 두 손가락 가운데를 기준으로 확대·이동, 핀치 뒤 남은 손가락으로 이어서 이동, 고해상도 교체는 손을 뗀 뒤 디코드 후. 배율 표시는 ×1.4처럼, 두 번 탭은 2.5배
- 끌어서 평가: 평가 직후 바로 끌어도 평가가 빠지지 않음(날아가는 사진을 즉시 마무리), 짧고 빠른 튕기기 인식, 넘어갈 사진이 없으면 제자리로
- 작은 화면에서 세로 사진 위아래가 잘리던 문제, 작은 화면 제스처 안내 한 줄 유지
- 결과: 보기 전환을 범위 선택에서 떼어 「인스타 피드로 미리보기」 글자 링크로
- 스토리 카드: 완료 화면 버튼 이름을 「스토리 카드」로, Android 완료 화면에도 진입 추가, Android에서 갤러리 저장·공유(기기 연결 saveImage/shareSavedImages), 날짜 각인 사본은 고해상도로
- Android 0.5.1(14)

## 웹 사용
사진 폴더 또는 JPEG 파일을 고르면 EXIF 촬영일로 날짜 묶음을 만듭니다. 사진은 브라우저 안에서만 처리하고 서버에 올리지 않습니다. 고른 사진은 공유하기, 한 장씩 받기, 원본 ZIP(STORE)으로 받습니다. 평가 기록은 이 브라우저 localStorage에 파일 이름·크기·수정 시각 기준으로 남아, 같은 사진을 다시 고르면 이어서 평가합니다. 웹과 Android 평가 기록은 따로입니다.

## 구조
- `index.html`: 데스크톱 소개 + 오른쪽 앱 화면(iframe). 휴대폰에서는 `app/`으로 바로 이동
- `app/index.html`: 앱 화면 (웹)
- `assets/app/`: `app.js`(화면·평가·저장), `app.css`, `story.js`(스토리 카드·날짜 각인 사본), `icon.svg`
- `assets/pp1/`: PP-1 토큰·컴포넌트·글꼴(DSEG7 OFL 포함)·필름 질감
- `assets/web-exif.js`, `assets/web-download.js`: 브라우저 EXIF 읽기, 원본 ZIP·다운로드
- `assets/demo/`: 예시 사진 13장 (촬영일은 체험용)
- `android-app/`: Android 프로젝트. `app/src/main/assets/www`에 같은 화면을 루트 경로(`assets/`)로 넣어 둠
- 소스 원본은 로컬 `claude-design-standalone/web-pp1-auto`. 웹과 www는 그 소스를 옮긴 것

배포: main에 올리면 pages.yml이 `index.html`, `manifest.webmanifest`, `app/`, `assets/`를 GitHub Pages로 배포. `android-app/app/build.gradle`의 versionName을 올려 main에 반영하면 release-android.yml이 그 버전 릴리스가 없을 때 자동 릴리스(등록 키로 서명). 태그 `android-vX.Y.Z`나 Actions 직접 실행도 가능.
